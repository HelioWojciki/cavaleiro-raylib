Cavaleiro — Jogo 2D com Raylib

Sobre o jogo
Cavaleiro é um jogo 2D de ação em que o jogador controla um cavaleiro que enfrenta ondas de inimigos e, em seguida, três chefes em ordem crescente de dificuldade: fácil, médio e difícil. Durante a partida, o jogador acompanha a quantidade de vidas e a pontuação na tela. Ao perder todas as vidas, aparece a tela de Game Over, com a opção de reiniciar a partida.

Como jogar
- W, A, S, D — movimentar o cavaleiro.
- Botão esquerdo do mouse — atacar.
- Enter — reiniciar após Game Over.
- Objetivo — derrotar os inimigos comuns e vencer os três chefes.
