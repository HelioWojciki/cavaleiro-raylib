Instalação e como jogar
1. Clique em Code → Download ZIP no GitHub.
2. Extraia o arquivo ZIP.
3. Abra a pasta do jogo e execute jogo.exe, mantendo a pasta resources junto dele.
O objetivo é derrotar os zumbis e, depois, os três chefes: fácil, médio e difícil. O jogador começa com 3 vidas. Se perder todas, aparece Game Over. Ao vencer o último chefe, aparece a mensagem de vitória.

Comandos:
- W, A, S, D: movimentar o cavaleiro.
- Mouse esquerdo: atacar.
- Enter: reiniciar após vencer ou perder.
- Tab: mostrar ou esconder as áreas de colisão.
Tecnologias utilizadas
- C: linguagem usada no código.
- Raylib: biblioteca usada para criar o jogo.
- Visual Studio Code e GCC: edição e compilação do código.
- GitHub: publicação do projeto.

Utilizamos inteligência artificial como apoio em algumas partes do jogo:
- Ajustes no sistema de colisões.
- Lógica para os chefes receberem dano.
- Revisão de trechos do código.
- Correção de pequenos erros.
- Pequenos ajustes na pontuação.
O grupo testou e ajustou o funcionamento do jogo.
